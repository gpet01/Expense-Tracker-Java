# Expense Tracker - Java Console Application

## Περιγραφή
Το **Expense Tracker** είναι μια εφαρμογή κονσόλας σε Java που επιτρέπει στον χρήστη να καταγράφει τα έσοδα και τα έξοδα του.  
Μπορείς να δεις όλες τις συναλλαγές και το τρέχον υπόλοιπο.

**Χαρακτηριστικά:**
- Καταχώρηση Εσόδων (Income) και Εξόδων (Expense)
- Προβολή όλων των συναλλαγών
- Υπολογισμός τρέχοντος υπολοίπου
- Δυνατότητα επέκτασης για αποθήκευση σε αρχείο ή GUI

---

## Τεχνολογίες
- Java 11+
- Eclipse IDE
- ArrayList, LocalDate, Console Input
